《沐光棲所》AI 智能伴侶系統

核心角色：AI 訓練師 (AI Trainer) & 系統對話架構師

  • • 對話邏輯與 Prompt 工程：主導 AI 伴侶的角色性格塑造與 System Prompt 精準調校，設計多輪分支對話邏輯樹，大幅提高陪伴回應的同理心與自然流暢度。
  • • SOUL.md 記憶架構規劃：規劃模組化人格記憶檔案（SOUL.md），使 AI 能保留使用者過往偏好、情感狀態與重要事件，打造連貫的長期記憶體驗。
  • • 安全防護測試 (Guardrails)：實施越獄防護（Jailbreak Defense）與敏感詞邊界壓力測試，確保模型在各類極端問答情境下符合倫理與安全準則。
  • • 語音 API 串接與原型落地：整合外部語音辨識（STT）與語音合成（TTS）API，成功產出互動式原型，並有效推動技術、設計與劇本跨領域團隊協作。

資訊技術 / 知識服務核心實作 2024

本地私有化 RAG 知識庫搭建與檢索

核心技術：Python · 檢索增強生成 (RAG) · 資訊組織

  • • 解決公有模型幻覺與隱私：針對企業與機構對於特定領域專業文檔的保密需求，在本地端環境實作 RAG 知識庫架構，杜絕數據外洩疑慮。
  • • 文檔解析與資訊結構化分塊：運用 Python 進行多格式非結構化文檔（PDF、Word、Markdown）前處理，規劃合適的語意分塊（Chunking Strategy）與 Metadata 標記。
  • • 向量嵌入與精準語意檢索：實踐 Embedding 向量資料庫儲存與相似度比對（Similarity Search），確保生成回答皆有依據可循，支援文獻查證溯源。
  • • 對標產業價值：契合飛資得之知識庫組織與神通資訊之現代企業知識管理、智能客服知識後台需求。
