《沐光棲所 Komorebi》AI 智能伴侶系統

核心角色：AI 訓練師 (AI Trainer) & 系統對話架構師

  • • 對話邏輯與 Prompt 工程：主導 AI 伴侶的角色性格塑造與 System Prompt 精準調校，設計多輪分支對話邏輯樹，大幅提高陪伴回應的同理心與自然流暢度。
  • • SOUL.md 記憶架構規劃：規劃模組化人格記憶檔案（SOUL.md），使 AI 能保留使用者過往偏好、情感狀態與重要事件，打造連貫的長期記憶體驗。
  • • 安全防護測試 (Guardrails)：實施越獄防護（Jailbreak Defense）與敏感詞邊界壓力測試，確保模型在各類極端問答情境下符合倫理與安全準則。
  • • 語音 API 串接與產品落地：整合語音辨識（STT）與語音合成（TTS）API，產出互動原型並建立專屬展示網站，有效推動跨領域團隊協作。

SCP-6820 終端資料庫系統（湖區監測中心）

核心技術：PostgreSQL · SQL 資料庫設計 · 端點權限控管

  • • 終端系統與安全架構：以 SCP 基金會科幻情境為發想，打造「山谷港異常湖區監測總部」資料庫系統，實作存取權限驗證與模因防禦安全機制。
